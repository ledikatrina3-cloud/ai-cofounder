# Telegram allowlist

Список разрешённых `chat_id` для каждого Telegram-канала AI-Cofounder.
Источник правды для allowlist-middleware ([src/telegram/](../src/telegram/)).

Формат:
- Секция `## <канал>` — отдельный список на канал.
- Записи: `- <chat_id>` или `- <chat_id> # <комментарий>` (положительное число — личка, отрицательное — группа/канал Telegram).
- Парсер игнорирует прочий текст в файле — комментарии и заголовки не ломают работу.

Каналы:
- `founder-bot` — основной бот фаундера (фаза 1.2). Изменения через `pnpm pair`.

Support-бот не использует эту Page: у него собственный source-list в
[`config/support-source.md`](support-source.md), секция `## support-source`,
изменения через `pnpm pair:support` (фаза 2.1a). Это сделано потому, что
семантика разная: тут — «кому разрешено писать боту», там — «откуда читать
сообщения клиентов».
