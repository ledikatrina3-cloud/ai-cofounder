# Support-bot source channels

Список `chat_id`-ов, откуда AI-Cofounder читает входящие сообщения support-бота
проекта (фаза 2.1b, stateless fetch — see
[src/telegram/](../src/telegram/),
секция «Support-бот»). Read-only — бот не отвечает.

Формат:
- Секция `## support-source` — единственный список source-каналов.
- Записи: `- <chat_id>` или `- <chat_id> # <комментарий>`
  (положительное число — личка клиента, отрицательное — группа/канал Telegram).
- Парсер игнорирует прочий текст в файле — комментарии и заголовки не ломают работу.

Изменения этого файла идут через `pnpm pair:support` (фаза 2.1a). Ручная правка
тоже легитимна — формат стабилен. Идемпотентно: повторный `pair:support` с тем
же chat_id не дублирует.
