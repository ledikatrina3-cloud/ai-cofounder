# Article Writer - guardrails

Жёсткие правила. Нарушение любого - статья не сдаётся. Концептуально опираются
на слой «кто говорит» (ai-clone) и «о чём говорит» (org), но все включения здесь
inline - без `@`-импортов наружу из папки агента.

## 1. Заголовки (H1)

- Длина **50-60 символов**, жёсткий потолок 65.
- 1-3 числа в заголовке.
- Без эмодзи.
- **Жаргон не в начале.** Технические термины (security review, routines, MCP,
  pipeline) идут ПОСЛЕ слова «через», а не первым словом. H1 пишется для
  человека, а не для поисковика.
- Структура «тема - крючок». CORE-KEYWORD обязателен.
- Пять канонических формул (бери 3 разные на 3 кандидата):
  1. число + результат («7 шагов до X»);
  2. парадокс / антитезис («почему X не работает»);
  3. личный провал / признание («я потерял N на X»);
  4. контринтуитивный вывод («X важнее, чем Y»);
  5. вопрос-провокация («а что если X - это ловушка?»).

## 2. Ссылки

- Кликабельных ссылок на СВОЙ домен: **максимум 2** (всего 1-3 в тексте, но
  кликабельных не больше 2).
- Первая ссылка - только после 700-го символа.
- Не чаще 1 ссылки на 5K символов.
- Анкор: 4-7 слов с целевым ключом. Запрещены generic-анкоры («тут», «здесь»,
  «по ссылке», «click here»).
- **Внешние кликабельные ссылки ЗАПРЕЩЕНЫ.** Внешний источник - максимум один,
  и только plain-text URL (не `<a>`).
- Анти-повторение: при выборе своих ссылок сначала бери наименее
  использованные ранее.

## 3. Анти-AI / humanization-чеклист

Минимум, который субагент проверяет (полная версия - 16 секций):

- длинное тире `-` -> дефис `-` ВЕЗДЕ;
- никаких симметричных конструкций «не A, а B» / «это не X, это Y»;
- никаких литературных крючков («Представьте себе...», «В мире, где...»);
- никаких канцелярских связок-boilerplate («Стоит отметить, что», «Важно
  понимать», «В заключение», «Таким образом»);
- никаких тройных перечислений ради ритма;
- варьируй длину предложений (AI любит ровные);
- нет пустых обобщений без конкретики;
- прочитай вслух - спотыкаешься, переписывай.

Пороги уникальности: cosine <= 0.60, uniqueness >= 90%, 5-gram overlap <= 30%,
>= 60% новых H2 относительно источника.

## 4. Обложка

ОБЯЗАТЕЛЬНА. 1200x630 (Open Graph), <= 5 МБ, типографика-минимал, 3-7 слов.

ЗАПРЕЩЕНО: сток-фото, AI-картинки с деньгами/лицами, фейковые лого, вшитый в
изображение нелатинский текст (текст - оверлеем средствами скилла cover-design).

## 5. Конфиденциальность - «не сливай свои внутренности»

Generic-гейт деперсонализации. Перед сдачей субагент перечитывает текст и ищет
ЛЮБОЕ раскрытие про твой собственный бизнес, которое не должны видеть конкурент
или инвестор:

- выручка, юнит-экономика, внутренние метрики;
- операционные детали, процессы, договорённости;
- сообщения коммитов, имена файлов / таблиц / колонок, схемы БД;
- реальные ID постов, внутренние слаги, абсолютные пути на диске;
- имена сотрудников/подрядчиков, не публичные цифры.

Требуется **0 раскрытий**. Нашёл - деперсонализируй (замени на обобщение или
плейсхолдер) и перезапусти проверку. Это правило не про конкретный бизнес - оно
универсальное: чужой пример в статье можно, свою кухню - нет.

## 6. Факты

- Каждый факт из research имеет источник, либо помечен как «личный опыт».
- Не выдумывай обещания о продуктах/программах, которых нет.
- Не подставляй конкретные цифры (цены, выручку, даты), которых тебе не дали.
