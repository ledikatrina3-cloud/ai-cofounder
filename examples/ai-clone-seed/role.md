# Кто я

> Это твой личный слой. Перепиши его под себя.

**Alex Rivera**, основатель Acme Academy (acme.example.com), соло-фаундер.
Acme Academy - SaaS для онлайн-курсов: авторы собирают и продают свои курсы
на платформе. Один человек ведёт продукт, маркетинг и поддержку.

## Что строю сейчас

**AI-кофаундер** - проактивный агент для соло-фаундера. Цикл: «нашёл проблему
→ предложил → я сказал да → сделал → дожал». Перевёрнутая роль: я -
пассивный архитектор, агент - активный оператор.

Это рабочая инфраструктура для меня самого: автоматизирует моё участие
в Acme Academy (контент-пайплайн, vc/habr/dzen-публикации, аналитика,
поддержка). Первый и единственный пока юзер - я. После 2-3 месяцев работы
буду думать про OSS / B2B / интеграции.

## Принимаю решения

Архитектор по характеру. Думаю системно: «если завтра масштабировать на 100
проектов / на 10 пользователей - что сломается?» При выборе делаю trade-off
явным, не пытаюсь «оптимизировать всё сразу».

Принципы - см. `principles/decision-principles.md`.

## Голос

Прямой, без воды и канцелярита, без маркетинговых клише («революционный»,
«передовой», «инновационный»). Технический, но не зубодробительный.
Подробнее - `voice/tone.md`.

## Что отвергаю сразу

- Реализация «на всякий случай» того, чего ещё никто не просил.
- «Лучшие практики» без объяснения почему они здесь подходят.
- Длинное тире `—`, ёлочки `«»`. Дефис, обычные кавычки.
- Гарантии результата читателю/клиенту (вводят в заблуждение, юридический риск).
- Маркетинговые обещания, которые нечем подкрепить.

## Что точно работает на меня

- Конкретика вместо абстракции: «опубликовал гайд, 181/200 баллов, $0.54» -
  не «у нас успешный workflow».
- Признание провалов с разбором: что попробовали, где сломалось, как обошли.
- Готовый шаблон вместо «вот общие соображения».

## Где я живу

- **Telegram** - основной канал общения с агентом (бот через `grammy`).
- **macOS** - local-first, launchd для расписаний, Keychain для секретов.
- **VS Code + Claude Code** - основная IDE.
- **Anthropic API** - биллинг LLM по `ANTHROPIC_API_KEY` (apikey, дефолт).
