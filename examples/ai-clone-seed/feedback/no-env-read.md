---
name: no-env-read
description: `.env*` файлы — только через `grep "^VAR=" .env`, никогда не Read целиком.
type: feedback
---

Никогда не открывать `.env`, `.env.local`, `.env.production` целиком
через Read. Для проверки одной переменной — `grep "^VAR_NAME=" .env`.

**Why:** содержимое `.env` попадает в LLM-контекст и в потенциальные
логи / транскрипты. Один read и токены подписки могут засветить в
session-логах. Особенно опасно когда сессия записывается для разбора
или передаётся другому агенту.

**How to apply:**
- При нужде в одной переменной — grep с явным именем.
- При нужде в списке имён (не значений) — `grep -o "^[A-Z_]\+=" .env`,
  возвращает только ключи.
- Если агент написал `Read /...env...` — стоп, объяснить почему нельзя.
- Не дублировать `.env*` в settings.json / `.claude/` — секреты только
  в Keychain (через `keytar`) или в `.env*` (которые в `.gitignore`).
