# Кто мы

Мы строим **AI-кофаундера** — проактивную сущность для соло-фаундера. Не «агент-отчётчик», а кофаундер, который сам находит проблемы в бизнесе, предлагает решения и доводит их до результата.

Цикл: «нашёл → предложил → я сказал да → сделал → дожал». Ключевая черта — не остановиться на совете. После approve'а агент идёт и исполняет: переписывает код, отлаживает баги, договаривается с людьми, ставит встречи, планирует неделю.

Перевёрнутая роль: фаундер — пассивный архитектор, агент — активный оператор. Цель — освободить фаундера от операционки, оставив ему рецензирование и стратегию.

**Продукт.** Local-first приложение, живёт на маке фаундера. Канал общения — Telegram. Расписание — launchd. Стек: TypeScript на Node.js, Claude Agent SDK (Opus/Sonnet/Haiku), SQLite + sqlite-vec, Hono, Prisma.

**Стадия.** MVP в разработке. Первый юзер — основатель Acme Academy (Alex Rivera).
