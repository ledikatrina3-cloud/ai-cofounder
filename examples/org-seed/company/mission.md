# Миссия

## Большая ставка

Соло-фаундер должен иметь возможность построить **AI-first компанию из
одного человека** — не «использовать AI как ещё один инструмент», а собрать
систему, в которой *проактивный агент — основная рабочая сила*.

Один человек + AI-кофаундер = команда из 10. Без найма команды. Без потери
контроля. Без операционного выгорания.

## Боль которую решаем

Фаундер хочет быть **архитектором** — придумывать продукт, видеть стратегию,
говорить с клиентами. Но операционка съедает 80% времени: писать посты,
триажить support, считать выручку, публиковать черновики, проверять метрики.
Результат — фаундер живёт в реактивном режиме, проект не растёт стратегически.

Нужен **оператор**, который вернёт фаундеру архитекторскую роль. Не отчётчик
(«вот данные за вчера»), а **исполнитель** («нашёл проблему → предложил →
после approve пошёл и сделал»).

См. [[../audience]] для развёрнутого ICP.

## Перевёрнутая роль

| Классика | AI-Cofounder |
|---|---|
| Фаундер — активный оператор, AI помогает | Фаундер — пассивный архитектор, AI — активный оператор |
| AI отвечает на вопросы | AI ищет вопросы и приносит решения |
| Reactive: спросил → ответил | Proactive: нашёл → предложил → дожал |
| Команда из 5+ человек | Один человек + структурированный контекст + Claude |

## Цикл работы AI-кофаундера

```
1. Нашёл проблему (мониторинг → support-чат / БД / метрики)
2. Предложил решение (план + цена + альтернативы)
3. Я сказал «да» (Telegram, один тык)
4. Сделал (код / контент / публикация)
5. Дожал (метрики, follow-up, ретро)
```

Ключевая черта — **дожимание**. Большинство AI-агентов останавливаются
на шаге 2 («вот совет, делай сам»). Кофаундер идёт до шага 5.

## Принципы продукта

### Local-first
Всё живёт на маке фаундера. Никаких облачных SaaS с данными в чужих
серверах. Причина: контроль данных, ноль операционных издержек, ноль
внешних точек отказа.

### Прозрачный per-token биллинг
LLM-вызовы напрямую в Anthropic API по `ANTHROPIC_API_KEY` (`apikey`, дефолт,
см. src/llm/transport.ts). Причина: прозрачный расход в `audit.spend.usd`, режем
перерасход бюджет-гардами.

### Каждое решение — с trade-off
Не «давайте сделаем X», а «вариант А или Б, цена и выгода каждого, я
рекомендую А, потому что …». Скрытые компромиссы выстреливают через
месяц.

### Telegram — единственный канал
Все сотрудники-агенты пишут фаундеру в один Telegram-канал. Никаких
отдельных дашбордов, push-уведомлений, email-алёртов. Один канал, единый
формат.

См. также [[../identity]] (что строим) и [`../../ai-clone/principles/decision-principles.md`](../../ai-clone/principles/decision-principles.md) (как принимаем решения).

## Долгосрочная картина

**Сегодня:** один пользователь (фаундер сам), MVP, локальная инсталляция.

**Через 3 месяца:** open-source. Любой соло-фаундер может клонировать репо,
прописать свои downstream-проекты в `config/projects.md`, и через 30 минут
получить рабочего AI-кофаундера под свой бизнес.

**Через год:** marketplace skills и routines. Сообщество шарит конкретные
сотрудники («Бухгалтер платёжного провайдера», «SMM Telegram-канала», «Аналитик YouTube»).
Фаундер собирает свою команду из готовых компонентов как Lego.

**Через 3 года:** AI-first company стандарт. «Команда из 10 человек» больше
не равно «10 человек на зарплате» — это «1 архитектор + структурированный
контекст + Claude».
