# Visual assets для cover-генератора

Реестр визуалов / личных ассетов для встраивания в обложки spoke-статей.

> Важно: движок НЕ поставляет логотипы или маскотов сторонних брендов (товарные
> знаки принадлежат их владельцам). Все картинки в `assets/` — это ТВОЯ
> собственная оригинальная графика, которую ты добавляешь сам. Папки ниже —
> просто механизм организации; по умолчанию они пусты.

## Структура `assets/logos/<brand>/`

Один **слот** = одна папка. В папке — **набор разных визуалов**, чтобы каждая статья получала свой cover (нет визуального однообразия в ленте). Имя папки — произвольный slug, который ты сам свяжешь с темой в маппинге ниже.

```
assets/logos/
├── <slug-a>/                 ← твои оригинальные визуалы для темы A
│   ├── visual-1.svg
│   ├── visual-2.png
│   └── ... (добавлять свои)
├── <slug-b>/
│   └── ...
└── ...
```

## Выбор картинки для конкретной статьи

В frontmatter draft'а:
```yaml
ai_brand: <slug-a>             # имя папки в assets/logos/
```

Cover-генератор:
1. Резолвит `ai_brand` → папка `assets/logos/<slug>/`
2. Сканирует все файлы (SVG / PNG)
3. **Deterministic random**: hash от title slug → index в массиве файлов. Одна и та же статья всегда даёт один визуал, но разные статьи — разные.
4. Загружает выбранный файл, встраивает в template

Если папка пуста или отсутствует — обложка рендерится без визуала (graceful fallback), без падения.

Альтернатива: `cover_pick: random | <filename>` — можно указать конкретный визуал, если не доверяешь рандому.

## Как добавить новые картинки

### Своя графика

Кладёшь СВОИ оригинальные SVG/PNG в нужную папку `assets/logos/<slug>/`. Cover-генератор автоматически подхватит при следующем render'е. Именуй по содержанию (`hero-terminal.png`, `mascot-wave.svg`).

### Через AI-генерацию (Midjourney / SDXL / DALL-E / Nano Banana)

Если нет готовых картинок — генерим. Промпт берётся из методологии cover-design. Полученные PNG кладём в папку как `gen-<slug>.png`.

## Personal assets — фаундер

`assets/people/` — для фото фаундера. Используется когда статья от первого лица.

Положи туда:
- `founder-headshot.png` — портрет 1024×1024
- `founder-cutout.png` — с прозрачным фоном
- `founder-square.jpg` — квадрат

Cover-генератор при `frontmatter.author_face: true` встраивает headshot в правый нижний угол.

## Маппинг category-slug → folder

Для авто-выбора заведи свой маппинг тем на имена твоих папок:
```typescript
const BRAND_BY_TOPIC: Record<string, string | null> = {
  'topic-a': '<slug-a>',
  'topic-b': '<slug-b>',
  // generic — без визуала
  'generic': null,
};
```

Если слот не определён (общая статья) — cover-генератор использует абстрактный визуал (типографика + геометрия, без конкретного логотипа).

## Юр.статус

Используй ТОЛЬКО графику, на которую у тебя есть права: собственная иллюстрация, AI-генерация, или ассеты с явно совместимой лицензией (с указанием автора, если лицензия этого требует). НЕ встраивай чужие товарные знаки, логотипы и маскотов брендов — это IP-риск для публичного репозитория и публикаций.

## Технические требования

- **SVG предпочтительнее PNG** — масштабируется, малый вес. Использовать когда есть.
- PNG: только когда нет SVG. Размер исходника ≥ 1280px по короткой стороне (cover 1920×1080 — нужен запас).
- Прозрачный фон если возможно (SVG-нативное, PNG-32 с alpha).
