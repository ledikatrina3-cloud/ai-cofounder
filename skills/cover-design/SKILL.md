# cover-design

## Когда использовать

Когда draft готов и нужна обложка для публикации: блог, Telegram, превью в
поиске или соцсетях. Скилл генерирует SVG из библиотеки шаблонов и подставляет
title статьи.

Не используй для premium-картинок через внешнюю AI-генерацию. Для стандартной
статьи достаточно типографской SVG/PNG обложки.

## Источник правды

Перед генерацией обязательно прочитай `org/cover-design-brief.md`. Если есть
`org/design-system.md`, учитывай его как общий visual law проекта.

Палитра для шаблонов:
- фон: `#17120F`;
- акцент: `#C7A27A`;
- текст: `#F4EFEA`;
- приглушенный текст: `#D8CEC4`;
- рамка: `#3A3028`;
- глубокая тень: `#0E0B09`.

Запрещено использовать старые или чужие варианты: белые cover, Georgia/Times New
Roman, LONG READ, AI-Cofounder, URL, CTA на обложке, фиолетово-синие градиенты,
красный solid и старые цвета `#141413`, `#d97757`, `#ede9e3`.

## Алгоритм

1. Возьми title из frontmatter статьи или H1.
2. Выбери template по задаче:
   - `minimal` - фирменный темный фон, крупный заголовок и спокойная рамка;
   - `dark-stripe` - темный фон с акцентной вертикальной полосой;
   - `geometric` - темный фон с неброским геометрическим паттерном;
   - `gradient` - мягкий фирменный градиент без фиолетово-синей схемы;
   - `accent` - акцентная композиция для более сильных тезисов.
3. Запусти скрипт:

```bash
pnpm exec tsx skills/cover-design/scripts/generate.ts --title "<title>" --template <name> --out <path>
```

Скрипт пишет SVG и, если доступен `sharp`, PNG 1200x630 под Open Graph.

## Ограничения

- На обложке должен быть только title или его короткая cover-версия, если title
  длиннее 80 символов.
- Кириллица поддерживается системным sans-serif шрифтом.
- В PNG нужен безопасный правый отступ минимум 70px.
- Не добавляй сток-фото, AI-картинки, лица, деньги, fake logos и рекламный текст.
