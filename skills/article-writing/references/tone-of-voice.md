# Tone of voice (placeholder)

Базовый тон — берётся из `org/brand-voice.md` (он автоматически инжектится
в твой system prompt от runtime для category=writing). Этот файл — addon
поверх org-уровня, если для конкретного формата (статья vs тред vs email)
нужны нюансы.

## По умолчанию

См. `org/brand-voice.md`. Если ничего не сказано отдельно — следуй org.

## Для длинных статей

- Можно чуть формальнее, чем в Telegram-постах
- Допустима первая аналитическая фраза без «крючка»
- Но не настолько формально, чтобы потерять личность
