# Topics backlog

Очередь тем для маркетинг-исследователя. Формат — markdown с `[ ]`/`[x]`
чекбоксами, разделён на секции по приоритету. Researcher берёт первую
подходящую публичному бизнесу тему `[ ]` из «Высокий приоритет», после
публикации writer-editor меняет на `[x]` и добавляет дату.

Публичный бизнес: кастомные автоматизации ручной офисной рутины малого и
среднего бизнеса. Внутренние темы про AI-Cofounder, skills, orchestration,
Codex/Claude, prompt engineering и локальный runtime не брать для публичного
блога без явного файла `topics/article-writer-next.md`.
