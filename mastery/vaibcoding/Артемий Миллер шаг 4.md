# Артемий Миллер шаг 4: Папка idea

## Зачем

`idea/` - это "пять дней подумать и один раз сделать". Здесь человеческая хотелка превращается в ясный замысел продукта до кода. AI не должен угадывать, что ты имела в виду.

## Что создать

Одиннадцать разделов: идея, видение, аудитория, исследование, принципы, предварительная архитектура, решения, способности, MVP, фазы, риски.

## Промпт для Codex

```text
Создай в корне проекта папку idea/ со следующей структурой:

idea/
├── README.md
├── 01-idea/{README.md, why-now.md, inspiration.md}
├── 02-vision/{README.md, day-in-the-life.md, success-criteria.md}
├── 03-audience/{README.md, jobs-to-be-done.md, segments.md}
├── 04-research/{README.md, analogs.md, methodologies.md, what-to-steal.md, what-to-avoid.md, delta.md}
├── 05-principles/{README.md, local-first.md, proactive.md, action-oriented.md, one-person-company.md}
├── 06-architecture/{README.md, agent-loop.md, memory-model.md, permissions.md, triggers.md, integrations.md, tech-stack.md, data-flow.md}
├── 07-decisions/{README.md, tech-decisions.md, product-decisions.md, trade-offs.md}
├── 08-capabilities/{README.md, analytics.md, communications.md, operations.md, product-dev.md, strategy.md}
├── 09-mvp/{README.md, one-killer-feature.md, scope.md, success-metrics.md}
├── 10-phases/{README.md, milestones.md}
└── 11-risks/{README.md, technical.md, product.md, strategic.md, operational.md}

В каждом файле сделай H1 с названием раздела и секцию "Черновик".
В idea/README.md сделай one-pager со ссылками на все 11 разделов через wikilinks.

После создания структуры проведи меня step-by-step через заполнение.
Правила:
1. Задавай вопросы по текущему разделу по одному.
2. Я отвечаю голосом или текстом, часто сумбурно.
3. Ты структурируешь ответ и записываешь в нужный файл.
4. После заполнения раздела переходишь к следующему.

Порядок:
01-idea -> 02-vision -> 03-audience -> 09-mvp -> 04-research -> 05-principles -> 06-architecture -> 07-decisions -> 11-risks.

Не пиши код. Не создавай приложение. Сейчас только папка идеи.
Запусти структуру и задай первый вопрос для 01-idea/README.md.
```

## Что важно

- `09-mvp/one-killer-feature.md` - золотая сцена. Не список фич, а один момент, ради которого продукт нужен.
- `05-principles/` - противоядия от будущих рисков.
- `11-risks/` пока можно заполнить черново, потом усилить шагом 4.

## Готовность

- Папка `idea/` создана.
- Заполнены минимум `01-idea`, `02-vision`, `03-audience`, `09-mvp`.
- Есть одна killer feature.
