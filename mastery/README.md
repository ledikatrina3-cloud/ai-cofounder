# Методология mastery

`mastery/` - это не библиотека пересказов. Это рабочая коллекция методов: коротких, сильных и применимых.

Главное правило: один автор = один файл, только методы, не пересказ.

## Формат мышления

Каждый файл автора должен отвечать на вопрос: что именно у этого человека стоит перенять в практику?

Не нужно пытаться сохранить все идеи автора. Ценность `mastery/` в отборе. Если метод нельзя применить, проверить, повторить, адаптировать или использовать как вопрос к задаче, он не подходит.

## Что записывать

- 1-2-3 лучших метода автора.
- Короткое описание каждого метода.
- Где метод особенно полезен.
- Как применить метод на практике.
- Какие ошибки возникают при поверхностном использовании.

## Что не записывать

- Пересказ книг целиком.
- Биографии без прямой пользы.
- Длинные цитатники.
- Общие вдохновляющие мысли без метода.
- Все идеи автора подряд.

## Базовая структура будущего файла автора

```markdown
# Имя автора

## Метод 1: название

Кратко: что это за метод.

Применять когда: в каких задачах он особенно силен.

Как использовать: конкретные шаги.

Ошибка: как метод обычно искажают.
```

`mastery/` должен оставаться концентратом. Чем меньше лишнего, тем сильнее папка.
