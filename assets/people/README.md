# Personal assets

Положи сюда фото фаундера (например, Alex Rivera) для использования в cover-генераторе.

Рекомендуемые форматы:
- `founder-headshot.png` — портрет лицом к камере, 1024×1024 (для side-by-side с артефактом)
- `founder-cutout.png` — фото с прозрачным фоном (для встраивания в cover без рамки)
- `founder-square.jpg` — квадратное превью

Используется в cover-template когда статья от первого лица (как автор делится опытом). См. `org/visual-assets.md`.
